## Способ 1: Один файл (для пользователей)

**Самый простой способ.**

1. Открой [`dist/neon-wings.lua`](../dist/neon-wings.lua) на GitHub
2. Нажми кнопку **`Raw`** (правый верхний угол)
3. **Ctrl+A** — выделить всё
4. **Ctrl+C** — скопировать
5. Открой **executor**
6. **Ctrl+V** — вставить в поле выполнения
7. Нажми **Execute** (или `F5`)

Готово! Крылья и нимб должны появиться.
