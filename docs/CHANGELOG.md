## [1.0.0] - 2025-09-27

### Добавлено
- 🪽 Базовые неоновые крылья для R6
- 🌈 Радужный нимб над головой
- ✨ Плавная spring-анимация (пружины с затуханием)
- 🎯 Реакция на движение:
  - Бег — ускоренный мах
  - Прыжок — взмах вверх
  - Падение — раскрытие крыльев
  - Поворот — центробежный сдвиг
- 🎨 3 режима цвета: `Rainbow`, `Gradient`, `Pulse`
- 🌈 3 режима нимба: `Rainbow`, `MatchWings`, `Gradient`
- 🎮 Управление клавишами:
  - `G` — вкл/выкл крылья
  - `H` — вкл/выкл нимб
- ⚙️ Полностью настраиваемый конфиг
- 📦 Модульная структура:
  - `config.lua` — настройки
  - `utils.lua` — утилиты (spring, makePart, makeMotor)
  - `physics.lua` — отслеживание движения
  - `wing.lua` — создание и анимация крыла
  - `halo.lua` — создание и анимация нимба
  - `init.lua` — точка входа
- 📄 Собранная версия `dist/neon-wings.lua` (один файл для executor)

### Исправлено
- 🐛 Фикс цвета перьев (`bendForce` → `fForce`)
- 🐛 Симметрия левого и правого крыла
- 🐛 Прозрачность spine (было видно "палку")
- 🐛 Ошибка `invalid argument #4 to 'format'`

### Известные проблемы
- ⚠️ Не работает в Evade (кастомная система ригов)
- ⚠️ Только R6 (R15 пока не поддерживается)
- ⚠️ Не реплицируется другим игрокам (видно только тебе)
